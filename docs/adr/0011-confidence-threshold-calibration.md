# 0011 · 置信度门槛 0.65 → 0.50（由评估集扫描得出）

- 状态：已采纳
- 日期：2026-09-15
- 相关：`Settings.acra_confidence_threshold`、`src/acra/postprocess/validator.py::apply_threshold`、`acra eval sweep-threshold`

## 背景

第 8 步置信度门槛是**最大的漏报来源**：20 用例真实跑分里 8 条漏报，逐条看下去大多是
「模型报出来了、锚在正确行、判了合理等级，但置信度没过 0.65」被丢掉。

原来的 0.65 是文档 §9.1 里给的默认值，**没有经过任何数据校准**。

## 决策

**门槛改为 0.50。**

评估方式：`acra eval sweep-threshold` 在一次真实跑分的**候选池**上重放不同阈值。
候选池是"过门槛之前的完整候选集"，而门槛是流水线最后一步，
所以同一份数据在各阈值下**严格可比**，且零额外模型成本、不受跑批随机性干扰。

| 阈值 | Precision | Recall | FP |
| --- | --- | --- | --- |
| 0.40 | 0.933 | 0.875 | 1 |
| **0.50** | **1.000** | **0.750** | 0 |
| 0.60 | 1.000 | 0.500 | 0 |
| 0.65（原值） | 1.000 | 0.500 | 0 |
| 0.75 | 1.000 | 0.438 | 0 |

0.65 → 0.50：Precision 不变、Recall +25 个百分点。
该幅度约为实测**跑批波动（±6.2pp）的 4 倍**，因此可以认为是真实提升而非噪声。

## 理由

- 文档 §11.2 给了两个目标（Precision ≥ 0.60、Recall ≥ 0.35），0.50 在两个方向上都优于 0.65；
- 文档同时强调"Precision 崩溃会导致团队弃用"，而 0.50 处 Precision 仍是 1.000，
  没有拿精度换召回；
- 实测波动给了判据：**任何小于 ±6.2pp 的改善都不能归因于改动**。
  0.55 与 0.50 之间 Recall 差 0.188，但如果只差几个点，就不该改。

## 配套改动（只改一处等于没改，实际有四处）

置信度门槛在代码与配置里存在**四处**，任何一处不一致都会造成"改了默认值却看起来没生效"：

1. `Settings.acra_confidence_threshold`（全局默认）
2. `RepoConfigView.confidence_threshold`（仓库配置视图默认）
3. `RepoConfig.confidence_threshold`（DB 列默认值）
4. **`.env` 里的 `ACRA_CONFIDENCE_THRESHOLD`** —— 优先级最高，实测就是它把 0.65 钉住了

前两处已同步为 0.50，并由 `tests/unit/test_settings_defaults.py`
**强制三者（含 DB 列）一致**。第四处**改为注释状态**，让它继承代码里那个经过校准的默认值 ——
钉在 `.env` 里会盖过校准结果，而且以后每次调默认值都会重演一次这个坑。

顺带在 `acra doctor` 里加了一行 `confidence gate`，同时显示**生效值**与
"是否等于代码默认值"：不再靠人记得去查 `.env`。
排查这类"改了没生效"时，先看这一行。

> 这个坑值得记住的样子：我改完代码默认值、测试也全绿（测试用的是 `Settings(_env_file=None)`），
> 但 `get_settings()` 实际读到的仍是 0.65。**"代码默认值改对了"与"运行时生效了"是两件事。**

## 后果与保留意见

- 未再降到 0.40：它能换到 Recall 0.875，但换来 1 条误报（Precision 0.933）。
  **16 个候选的样本量不足以判定这 7 个百分点是否真实**（分辨率约 6 个百分点），
  需要更大语料再验。这是本次决策里最不确定的一环。
- 本次扫描基于**单一轮次**的候选池。候选池受当轮模型输出影响，
  换一轮跑分得到的曲线会有差异（波动量级即 ±6.2pp）。
  结论方向（0.50 优于 0.65）在波动范围内稳健，但精确数值不应被当作定论。
- 门槛降低会把更多"需要人工判断"的结论放进输出。若后续 `Action rate` / `Noise rate`
  接入平台数据后显示噪音上升，应回退到 0.55 并重新评估。

## 备选方案

- 维持 0.65 靠提示词提升模型置信度：成本更高、周期更长，且见效不确定。
- 直接降到 0.40 最大化召回：精度代价与样本量都不支持，暂缓。
